# Independent SEC fundamental discovery v1

The strongest trailing-year result was **balance_sheet_quality** at **64.03% CAGR**, **1.659 Sharpe**, and **-16.89% drawdown**. This is a discovery result, not a promotion. Valuation was excluded because the available adjusted-price/share-count combination is not corporate-action consistent.
