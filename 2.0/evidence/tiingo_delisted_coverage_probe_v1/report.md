# Tiingo public-inventory coverage probe v1

Tiingo's public inventory contains **42,616** USD stock rows. It has date-overlapping symbol candidates for **883 of 952** usable SEC identities (92.8%).

Most importantly, it can potentially rescue **284 of 327** SEC identities whose recovered symbols failed at Yahoo (86.9%). Inventory coverage is at least **83.4%** from 2023 onward and **89.0%** at the latest decision.

These are candidates, not validated prices. A free Tiingo API token is required to retrieve metadata and adjusted histories, verify issuer identity, and measure actual decision-date coverage. No strategy test is authorized yet.
