# Tiingo terminal-outcome audit v1

The current authenticated batches contain **118** verified histories ending before the SEC staleness window. Acceptance-dated SEC metadata classifies **118** as merger/acquisition completions. Classification requires 8-K Items 2.01 and 3.01 plus either Item 5.01 or a Form 25-NSE, all within ten days of the last trade. For these cases the reproducible rule is liquidation at the final tradable close followed by cash. Unresolved cases require a -100% terminal-return sensitivity. Full strategy testing remains blocked until all priority price batches and outcomes are audited.
