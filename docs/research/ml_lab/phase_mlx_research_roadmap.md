# Phase MLX Research Roadmap

Phase MLX is an experimental, research-only hard-ML sandbox with high overfitting, selection-bias, and data-mining risk. No output from this roadmap is production-valid by default.

## Planned Sequence

1. MLX-0 folder structure + warnings
2. MLX-1 expanded ETF universe
3. MLX-2 date × ETF feature panel
4. MLX-3 tabular ML models
5. MLX-4 neural networks
6. MLX-5 sequence models
7. MLX-6 transformer
8. MLX-7 meta-labeling
9. MLX-8 deep RL allocator
10. MLX-9 model ensemble
11. MLX-10 final summary report

Each phase remains separated from production pins, production strategy logic, dashboard code, and candidate promotion unless a future explicit review process says otherwise.
